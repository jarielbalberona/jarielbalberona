## What it is

DataGPT is a data analytics platform centered on making complex data exploration more accessible through AI-assisted query workflows and guided analysis.

My work focused on the product engineering required to turn complex orchestration into an interface users could follow. That meant showing how a request moved through the system, what state it was in, when it failed, and how the user could recover.

## Why it matters

Analytics products fail when users cannot tell how a result was produced or whether the system is still behaving correctly. This work put query-state visibility, failure handling, and recovery paths into the core product experience instead of burying them behind a loading state and a hope that the backend would finish.

## Technical shape

The technical shape combined robust state management with disciplined visualization and interaction design. The goal was to make system behavior legible enough that AI-assisted analysis did not feel like an opaque black box to the people using it.
