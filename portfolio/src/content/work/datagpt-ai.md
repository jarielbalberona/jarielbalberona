## What it is

DataGPT is an AI analytics platform that allows users to interact with their data more intuitively. My work focused on the product engineering required to make AI-driven data exploration reliable, intuitive, and visually legible.

The priority was taking complex orchestration—translating user intent into queries and surfacing the resulting data—and turning it into an interface that operators could trust.

## Why it matters

Data analytics tools break when the user loses trust in how the system arrived at its answer. This project integrated query state visibility, failure handling, and recovery flows directly into the core product experience. Instead of treating long-running data workflows as an isolated backend detail, the UI actively surfaces system behavior.

## Technical shape

The execution balances robust state management with disciplined data visualization. The system makes complex query states legible, handles edge cases gracefully under load, and prevents the AI orchestration logic from becoming an operational black box.
