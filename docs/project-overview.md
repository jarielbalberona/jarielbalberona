# Project Overview

## Objective

Turn `jarielbalberona.com` into the primary public engineering home for Jariel Balberona.

The site should communicate:

- production software work
- modernization capability
- product, architecture, and delivery range
- current real work
- selected proof
- disciplined AI-assisted engineering workflow

## What This Site Is Not

- a generic portfolio
- a personality-heavy homepage
- a skill-bar resume
- an AI hype vehicle
- a dumping ground for every side project

## Primary Audience

- hiring managers evaluating senior engineering credibility
- founders or product teams looking for modernization or systems work
- engineers assessing technical seriousness and current relevance

## Primary Goal

Establish trust quickly and give serious visitors enough proof to continue the conversation.

## Secondary Goals

- create a stable home for current work and project proof
- support future short-form technical publishing
- align the public narrative across site, GitHub, and contact surfaces
