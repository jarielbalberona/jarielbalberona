# Content Operating Model

## Purpose

Keep public content current enough to stay credible without turning the site into a publishing obligation.

## Rules

- `Now` stays public only if it reflects current work.
- If `Now` becomes stale, update it or cut material until it is true again.
- `Work` only gets new entries when the project is strong enough to survive scrutiny.
- Do not add a second project just to make the page feel complete.
- Notes remain private or deferred until there is enough real material and a sustainable rhythm.

## Quality Bar

- grounded
- specific
- current
- senior
- concise

## Anti-Patterns

- dead blog infrastructure
- filler updates
- broad claims without proof
- AI commentary with no engineering substance
